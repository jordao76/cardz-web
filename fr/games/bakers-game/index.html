L'ancêtre plus strict de FreeCell

Baker's Game

Un jeu de cartes Jeu en plus · à télécharger
Famille FreeCell
FreeCell, Eight Off, Seahaven Towers, Penguin

But : constituez les quatre fondations en montant de l'As au Roi, chacune dans une seule enseigne.

  • Les colonnes du tableau se construisent en descendant dans la même enseigne (p. ex. un 6 de pique sur un 7 de pique).
  • Les déplacements se font strictement une carte à la fois. Une suite déjà ordonnée dans la même enseigne peut être déplacée en groupe, mais seulement dans la limite de ce que vous pourriez déplacer individuellement : (1 + cellules libres) × 2 pour chaque colonne vide.
  • Chacune des quatre cellules libres peut contenir une seule carte — utilisez-les comme zone de transit temporaire.
  • N'importe quelle carte peut commencer une colonne vide.
