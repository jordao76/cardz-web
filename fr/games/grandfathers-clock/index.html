Remontez chaque heure jusqu'à son chiffre

Grandfather's Clock

Un jeu de cartes Jeu en plus · à télécharger

But : complétez l'horloge. Chacune de ses douze fondations monte dans la même enseigne jusqu'à ce que sa carte supérieure indique l'heure où elle se trouve : le Valet pour onze heures, la Dame pour midi, l'As pour une heure.

  • Les douze cartes de départ sont posées avant la donne : le 9♣ à midi, puis dans le sens horaire 10♥ V♠ D♦ R♣ 2♥ 3♠ 4♦ 5♣ 6♥ 7♠ 8♦. Les rangs passent du Roi à l'As.
  • Les quarante autres cartes sont données face visible en huit colonnes de cinq, quatre de chaque côté de l'horloge.
  • Les colonnes descendent sans tenir compte des enseignes. Déplacez une carte à la fois.
  • N'importe quelle carte peut occuper une colonne vide.
