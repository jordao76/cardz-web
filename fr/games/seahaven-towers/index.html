Libérez d'abord les Rois

Seahaven Towers

Un jeu de cartes
Aussi appelé
Seahaven
Famille FreeCell
FreeCell, Eight Off, Baker's Game, Penguin

But : montez les quatre fondations de l'As au Roi, chacune dans une seule enseigne.

  • Dix colonnes de cinq cartes se construisent en descendant dans la même enseigne (un 6 de pique sur un 7 de pique).
  • Quatre cellules libres contiennent une carte chacune — deux d'entre elles reçoivent une carte à la donne.
  • Seul un Roi peut occuper une colonne vide : libérer les Rois est tout le problème de l'ouverture.
  • Une suite descendante de même enseigne peut être déplacée en groupe, mais seulement dans la limite de ce que les cellules libres et les colonnes vides permettraient de relayer à la main : (1 + cellules libres) × 2 pour chaque colonne vide.
