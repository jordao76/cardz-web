Thirteen columns, Kings sunk first

Baker's Dozen

One deck

Goal: build all four foundations up from Ace to King, each in a single suit.

  • Thirteen columns of four, all face-up. Columns build down in any suit, one card at a time.
  • An emptied column stays empty — nothing may be placed back into it. There is no stock and no redeal.
  • Sink the Kings first. A King outranks every card and an empty column takes nothing, so a King can never move, and whatever sits under one is stuck for good. By tradition you begin by sliding each King to the bottom of its own column: arm ORDER (press D) and drag it down. This is a convention you apply yourself, not a rule — skip it for a much harder game.
