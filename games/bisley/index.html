Build each suit from both ends

Bisley

One deck

Goal: move every card to eight foundations. Each suit is built from both ends at once: up from Ace and down from King. The two foundations may meet at any rank.

  • All 48 non-Aces start face-up in thirteen columns.
  • Tableau cards build one rank up or down in the same suit.
  • Move only one exposed card at a time. An empty column stays empty for the rest of the game.
  • A released King starts its matching downward foundation; choose carefully which end of a suit receives each available card.
