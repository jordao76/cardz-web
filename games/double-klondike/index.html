Two decks, nine columns

Double Klondike

Two decks Extra game · download

Goal: build all eight foundations up from Ace to King, each in a single suit.

  • Two decks are shuffled together, so every card appears twice and each suit has two foundations.
  • Tableau columns build down in alternating colour (e.g. a red 6 on a black 7). Move a single card or a valid run.
  • Only face-up cards can be picked up; uncovering a face-down card flips it.
  • An empty column can be started with a King (or a run headed by a King).
  • Draw from the stock to the waste one card at a time; recycle the waste back to the stock when it runs out.
