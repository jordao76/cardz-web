Klondike

One deck Draw: 1 · 3

Goal: build all four foundations up from Ace to King, each in a single suit.

  • Tableau columns build down in alternating colour (e.g. a red 6 on a black 7). Move a single card or a valid run.
  • Only face-up cards can be picked up; uncovering a face-down card flips it.
  • An empty column can be started with a King (or a run headed by a King).
  • Draw from the stock to the waste; recycle the waste back to the stock when it runs out.

Variants

The rules above are Klondike. Here is how the other variants differ.

Klondike (Draw 3)

Goal: build all four foundations up from Ace to King, each in a single suit.

  • Tableau columns build down in alternating colour (e.g. a red 6 on a black 7). Move a single card or a valid run.
  • Only face-up cards can be picked up; uncovering a face-down card flips it.
  • An empty column can be started with a King (or a run headed by a King).
  • Draw from the stock to the waste three cards at a time; only the top card of the waste is in play. Recycle the waste back to the stock when it runs out.
