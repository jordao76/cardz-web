Grandfather's Clock

Um baralho Jogo extra · para baixar

Objetivo: complete o relógio. Cada uma das doze fundações sobe no mesmo naipe até que a carta do topo mostre a hora em que está: Valete para as onze, Dama para as doze, Ás para a uma.

  • As doze cartas iniciais são colocadas antes da distribuição: o 9♣ às doze, depois no sentido horário 10♥ V♠ D♦ R♣ 2♥ 3♠ 4♦ 5♣ 6♥ 7♠ 8♦. Os valores passam do Rei ao Ás.
  • As outras quarenta cartas são distribuídas viradas para cima em oito colunas de cinco, quatro de cada lado do relógio.
  • As colunas descem sem considerar o naipe. Mova uma carta de cada vez.
  • Qualquer carta pode ocupar uma coluna vazia.
Ler o arquivo de design 62 linhas

Twelve foundations placed at fractional grid positions and turned to face the middle of a clock, each seeded with a named card and none capped: the next hour's seed is what stops each one. Este é o arquivo que o botão de download entrega. Crie um jogo explica cada parte dele (em inglês).
