Treze no terraço, e você escolhe a base

Terrace

Dois baralhos
Também conhecido como
The Terrace, Queen of Italy, Die Italienerin

Objetivo: monte os dois baralhos em oito fundações, subindo e alternando as cores a partir de uma carta-base que você escolhe, passando do Rei para o Ás.

  • Escolha a base primeiro: leve para qualquer fundação uma das três cartas do vale. Seu valor é a base das oito: com um 8, cada fundação começa num 8 e termina num 7. Cada carta desse valor começa uma fundação vazia, e os espaços delas mostram esse valor. Nada mais se move até você escolher, e então o vale se completa com nove pilhas a partir do monte.
  • O terraço de treze cartas se estende no alto. Só a carta da ponta está disponível, e só para uma fundação.
  • O vale desce alternando as cores, uma carta por vez. Um espaço vazio ali é preenchido na hora pelo monte; quando o monte acaba, ele recebe a carta do topo do descarte.
  • Vire o monte uma carta por vez para o descarte; a carta do topo do descarte vai para uma fundação ou para o vale. Não há redistribuição.
  • Sua pontuação é o número de cartas nas fundações, 104 numa vitória.
